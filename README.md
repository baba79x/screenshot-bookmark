## ✨ Why Screenshot Bookmark?

Your browser bookmarks are a graveyard of links you'll never revisit. You save a link, forget what was on the page, and never go back.

**Screenshot Bookmark fixes this.** Every saved page becomes a visual, annotated, searchable bookmark — stored entirely on your device. It’s like having a visual memory for everything you see on the web.

---

## 🚀 Key Features

### 📸 High-Fidelity Capture
- **Viewport**: One-click instant capture.
- **Full Page**: Automatic scrolling and pixel-perfect stitching.
- **Region**: Crosshair selection for precise crops.
- **Context Menu**: Right-click any image or link to capture instantly.

### ✏️ Pro Annotation Suite
- **Tools**: Arrows, highlights, rectangles, freehand pen, and text.
- **Privacy**: Built-in blur tool for redacting sensitive info.
- **Context**: Sticky notes for deep-dive thoughts.
- **Advanced**: Confidential stamps, grayscale mode, and image embedding.

### 🗂️ Visual Organization
- **Dashboard**: A premium, full-tab library (Linear/Arc inspired).
- **Structure**: Multi-level folders and a flexible tag system.
- **Search**: Instant visual search across titles, URLs, and tags.
- **Health**: Auto-detects broken links among your saved bookmarks.

## 🔒 Privacy-First Architecture

We believe your data should belong to you. Screenshot Bookmark is built on a **local-first** philosophy.

- **Zero Remote Servers**: No data ever leaves your browser.
- **No Analytics**: We don't track what you capture or how you use the app.
- **No Accounts**: Install and start capturing in seconds.
- **Transparent Permissions**: We only ask for what we need to function.

## 🛠️ Installation & Setup

### For Users (Chrome Web Store)
1. Install from the [Chrome Web Store](#).
2. Use the shortcut `Ctrl+Shift+S` to capture your first page.

### For Developers (Local Load)
1. Clone this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the repository folder.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+S` | Trigger Capture |
| `Esc` | Cancel / Close Panel |
| `A` / `H` / `N` | Arrow / Highlight / Note tools |

| `Delete` | Delete Selected in Library |
