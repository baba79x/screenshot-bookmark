Screenshot Bookmark

Privacy Policy

Last updated: May 9, 2026

Screenshot Bookmark is a browser extension that captures, annotates, and organizes webpage screenshots. This privacy policy explains what data the extension handles and how.

Screenshot Bookmark does not collect, transmit, or sell any user data. Everything stays on your device.

What Data is Stored

Screenshot Bookmark stores the following data locally on your device using your browser's built-in storage:

  • Screenshot images — the webpage captures you take
  • Metadata — page titles, URLs, capture dates, folder names, and tags you assign
  • Thumbnails — smaller preview versions of your screenshots
  • Settings — your personal preferences (capture mode, theme, etc.)

This data is stored using:

  • browser.storage.local — for the screenshot index and settings
  • IndexedDB — for full-resolution image data
  • Downloads folder — screenshots are also saved as image files to your Downloads directory

What Data is NOT Collected

  • ✕ No personal information (name, email, account)
  • ✕ No browsing history
  • ✕ No analytics or telemetry
  • ✕ No cookies or tracking pixels
  • ✕ No data sent to external servers
  • ✕ No third-party SDKs
  • ✕ No advertising or fingerprinting

Optional Broken Link Checker

Screenshot Bookmark includes an optional feature that checks whether your saved webpage URLs are still accessible.

Disabled by Default

When enabled, the extension sends lightweight HEAD requests to saved URLs approximately once per day. Only the HTTP status code is checked — no page content is downloaded. No data is sent to any third-party server. You can disable this at any time in Settings.

Permissions Explained

PermissionWhy It's Needed
activeTabTo capture a screenshot of the page you're currently viewing
tabsTo read the page title and URL for saving as bookmark metadata
storageTo save your screenshots, settings, and organizational data locally
unlimitedStorageTo store high-resolution screenshot images without browser limits
scriptingTo inject the capture, annotation, and save dialog UI into the current page
downloadsTo save screenshot image files to your Downloads folder
contextMenusTo add capture options to the right-click menu
alarmsTo schedule the optional broken link checker
notificationsTo show capture confirmation notifications

Data Sharing

Screenshot Bookmark does not share any data with the extension developer, third parties, advertising networks, analytics services, or any external server.

Data Deletion

All data stored by Screenshot Bookmark is deleted when you:

  • Uninstall the extension
  • Clear your browser data
  • Manually delete screenshots from the Library

You are in full control of your data at all times.

Changes to This Policy

If this privacy policy is updated, the changes will be noted here with a new "Last updated" date. Material changes will be communicated through the Chrome Web Store listing.
